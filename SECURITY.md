# Security Policy

## Supported Versions

Currently, only the latest version of AuthSphere on the `main` branch is actively supported with security updates.

## Reporting a Vulnerability

If you discover a security vulnerability within AuthSphere, please do not disclose it publicly.

Instead, please send an email to the project maintainers or use GitHub's private vulnerability reporting feature (if enabled for this repository). 

We take all security issues seriously and will attempt to respond to and resolve the issue promptly.
